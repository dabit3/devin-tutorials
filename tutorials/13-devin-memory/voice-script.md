# Devin Memory — voice script

Narrated by Nader Dabit (ElevenLabs voice `T8iHhGIWPm2GVYpQD1Am`). Each line plays over the shot named on the left.

| Shot | Narration |
| --- | --- |
| Home screen | This is Devin Memory. Devin remembers what it learns from working with you, across every session. |
| Typing the preference | Say you have a preference, like how you want status updates. |
| Sending it | You can tell Devin to remember it. |
| Devin replies | But Devin also saves and edits memories on its own as you work, with no approval step. Each time it does, an Updated memory card shows up in the session. |
| Memory card with the `MEMORY.md` diff | Your memories are Markdown notes in a Git repo, called your memory drive. |
| Customize → Memory | You can browse them anytime in Customize, Memory. |
| `MEMORY.md` selected | MEMORY.md holds your general preferences, and an index of your other notes. |
| Source view | Each entry is one line, with a link back to the session where Devin learned it. |
| Recent dreaming sessions | About once a day, Dreaming reviews your recent sessions. It merges duplicates, drops stale notes, and adds lessons it missed. |
| More actions → Turn off personal memory | Memory is personal to you, and you can turn it off here anytime. |
| Back on the home screen | New memories apply to future sessions. |
| Typing in a new session | So in a new session, ask for a status update. |
| Devin's three-bullet reply | Devin already follows your preference: three short bullets, and no emojis. |
| Outro | Memory is built on Agent Memory Repo, an open spec you can use in your own agents too. |
