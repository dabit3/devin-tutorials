# Devin CLI — voice script

Narrated by Nader Dabit (ElevenLabs voice `T8iHhGIWPm2GVYpQD1Am`), generated as one take at the voice's default settings and cut into lines locally. Each line plays over the shot named on the left.

| Shot | Narration |
| --- | --- |
| Trust prompt | This is the Devin CLI. Run devin in a project and trust the folder once. |
| Empty composer | Now Devin is running right in your terminal. |
| Slash command menu | Type / for commands like /model and /mode. |
| Accept edits on | Shift+Tab switches permission modes. |
| Smart mode on | Smart auto-approves actions the model judges safe. |
| Bypass permissions on | Bypass auto-approves everything. |
| Back to Accept Edits | This demo stays in Accept Edits. |
| Prompt with @ file mention | Describe the task, and use @ to point at files. |
| Devin working, sped up | Devin reads the code, edits files, and runs checks. |
| Command approval | In Accept Edits, it asks before running commands. |
| Summary | When it's done, you get a summary of what changed. |
| `git status` | The edits are on disk, ready to review and commit. |
| Orbit app, Clear button on Done | In the browser, the Done column now has a Clear button. |
| Clicking Clear | One click clears every finished issue. |
| New session | Start a new session for the next task. |
| Model picker | Pick a model with /model, like Fusion or SWE-2. |
| Model set to Fusion | Fusion is now the model for this session. |
| `/handoff` prompt | /handoff hands a task to a cloud Devin. |
| Which OS | Choose the cloud machine it runs on. |
| Handed off, session link | Cloud Devin picks it up, and you can follow along at the link. |
| `/cloud` command | /cloud lets you create, steer, and watch Devin Cloud sessions from here. |
| Switched to Devin cloud | New prompts now start a Devin Cloud session. |
| Typing `devin ssh` | And devin ssh takes you into the cloud machine. |
| Cloud box prompt | It's the same box the cloud Devin is using. |
| `git log` and `ls` on the box | Your repo is cloned and ready. |
| Outro card | That's the Devin CLI. |

The captions show the commands as typed (`/model`, `@`, `/handoff`, `/cloud`); `voSay` in `spec.js` spells them out for the voice ("slash model", "at", "swee two").
