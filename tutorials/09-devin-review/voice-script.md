| Bugs list | It also found two bugs, each with the file and line. |

| Proposed edit | Devin proposes a one-line edit. |
| Review button | Click Review to see it. |
| Commit Changes dialog | Check the diff and the commit message, then commit it to the pull request branch. |
| Refresh for latest | Refresh to load the new commit. |
| Fixed diff | Now the counts update whenever the board changes. |

| Review settings link | Then go to Review. |
