# Introducing Devin — voice script

Narrated by Nader Dabit (ElevenLabs voice `T8iHhGIWPm2GVYpQD1Am`). Each line plays over the shot named on the left.

## Home

| Shot | Narration |
| --- | --- |
| Home screen | This is Devin. It's an autonomous AI software engineer that writes, runs, and tests its own code. |
| Composer | Describe a task in plain English. If you could do it in a few hours, Devin can most likely handle it. |
| Ask / Agent switch | Ask mode explores the code and makes a plan, and Agent mode builds and ships. |

## A session

| Shot | Narration |
| --- | --- |
| Session in the sidebar | Every session is a conversation, plus Devin's own workspace. |
| Star kanban cards session | Here's an earlier session, where Devin added starred cards to a kanban board. |
| Adding the Computer tab | Devin has its own computer, with a browser, a shell, and an editor. |
| Computer tab | Here, it runs the app it's building in its own browser. You can watch, or take over at any time. |
| PR tab | Every change Devin made is in its pull request, right in the session. |

## The rest of the app

| Shot | Narration |

## A new task

| Shot | Narration |
| --- | --- |
| New session | Now, let's start a new session. |
| Model picker | Choose a model for the job, like Fusion, or a preview model like SWE-2. (spoken "swee two") |
| Environment picker | Pick where Devin runs: Linux, macOS, or Windows. |
| Ubuntu | We'll stick with Linux. |
| Composer | Give it a clear task, and say what done looks like. |
| Repo mention and typing | Mention the repo, then describe the change. |
| Sent | Press Enter, and Devin gets to work. |
| Working (sped up) | On its own, Devin reads the code, makes the change, and checks that the app still builds. |
| PR card | Then it opens a pull request, and offers to test the change in the browser. |
| Test the progress bar | Have Devin test it. |
| Computer tab (sped up) | Watch it click through the app on its own computer. |
| Recording card | When it's done, Devin sends a recording of the test. |
| Recording playing | Every check passed, with a video to prove it. |
| PR card | Open the pull request right in the session, |
| Diff | and review the diff and the checks. |
| Merge | Happy with it? Merge it. |
| Merged | Merged. |
| Outro | Clear task in, pull request out. |
