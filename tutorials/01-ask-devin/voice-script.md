# Ask Devin — voice script

Narrated by Nader Dabit (ElevenLabs voice `T8iHhGIWPm2GVYpQD1Am`). Each line plays over the shot named on the left.

| Shot | Narration |
| --- | --- |
| Home screen | This is Ask Devin. Ask questions about any codebase, and get answers grounded in the code. |
| Hover on the Ask toggle | Switch the composer to Ask mode. |
| Repo picker below the composer | Ask works on your indexed repos. It uses the one you have selected, or you can tag one. |
| Typing `@` | Type @, then pick the repo. (spoken: "Type at, then pick the repo.") |
| Typing the question | Now ask anything about the code, in plain English. |
| Devin working (sped up) | Devin searches the codebase on its own, and reads the files it needs to answer. |
| Answer with citations | Every answer cites the exact files and lines it came from. |
| Hover on `README.md:73-75` | Click a citation to jump straight to those lines. |
| README opened at lines 73-75 | The file panel jumps right to the cited lines. |
| Follow-up composer | When you are ready to build, describe the change you want. |
| Construct Devin Prompt button | Then click Construct Devin Prompt. |
| Prompt being generated (sped up) | Devin turns everything it learned into a ready-to-run prompt. |
| Generated prompt with Edit / Start Devin session | Review the plan, and edit it if you like. |
| Start Devin session button | Then start a Devin session with all of that context. |
| Session card in the conversation | The new session shows up right in the conversation, so you can track it without switching context. |
| Outro | Ask first, then build. |

## Prompts typed on screen
