## Overview
Make a small UI change to a web app and prove it with before and after screenshots.

## What's Needed From User
- The UI change to make

## Procedure
1. Clone the repo, install dependencies and start the dev server.
2. Open the app in the browser and take a "before" screenshot of the area you will change.
3. Make the change the user asked for.
4. Reload the app and take an "after" screenshot of the same area.
5. Open a PR with both screenshots in the description.

## Specifications
- The PR description shows the before and after screenshots side by side.

## Advice & Pointers
- Keep the change as small as possible.
- Take both screenshots at the same window size.

## Forbidden actions
- Don't add new dependencies.
