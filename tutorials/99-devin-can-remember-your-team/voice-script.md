# Devin can remember how your team works — voice script

Nader voice (`T8iHhGIWPm2GVYpQD1Am`, `eleven_multilingual_v2` from `_kit/settings.json`). The whole script is one ElevenLabs take, cut locally at sentence boundaries by `_kit/tools/vo.py` (transcript and sentence-cut checks passed). One narrated cut, music: Nader's `2-upbeat.mp3`.

## Title card (diagram)

Devin can remember how your team works, and get better every session.

## How it works (diagram)

Here's how it works. You correct Devin once. It saves a short note to your memory, Dreaming keeps those notes tidy, and every new session starts with them.

## Your memory drive (diagram)

Memory is a drive of short Markdown notes, personal to you. Each session starts with the main file, and opens the rest when the task needs them.

## Real: Customize → Memory

You can browse the whole drive under Customize, Memory.

## Real: repos/ledger-api.md note

## Dreaming (diagram)

About once a day, Dreaming reviews your recent sessions. It merges overlapping notes, drops stale details, and adds lessons it missed.

## Real: Recent dreaming sessions

This recent run pruned notes across nine files.

## Real: session 2 task typed, no reminder

## Real: session 2 report and PR #6 with CHANGELOG.md added

## Real: session 2 Changes panel, CHANGELOG.md diff
