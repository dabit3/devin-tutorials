# Devin in Slack — voice script

Narrated by Nader Dabit (ElevenLabs voice `T8iHhGIWPm2GVYpQD1Am`) for `12-devin-slack-nader.mp4`, and by Megan (voice `1FmDfZG0Nx2dCk793S1a`) for `12-devin-slack-megan.mp4`. Each is generated as one take at the voice's default settings and cut into lines locally. Each line plays over the shot named on the left.

| Shot | Narration |
| --- | --- |
| Fresh #devin-runs channel | Once Devin is in a Slack channel, you can tag it from any message. |
| @Devin mention menu | Type at Devin, and pick it from the list. |
| Typed !ask question | Start with bang-ask to get a quick answer about your code, without starting a full session. |
| Answer in the thread | The answer comes back in a thread, with links to the code it read. |
| Typed !fast task | For real work, tag Devin with a task. Bang-fast runs it as a full Devin session, in Fast mode. |
| Reply count on the task | A few minutes later, Devin replies in the thread. |
| Total in the thread | It did the work, and the total is right there. |
| Thread composer | Reply in the thread to keep going. You don't need to tag it again. |
| Follow-up answer | It picks up right where it left off. |
| Session link | Click the link to open the same session in the Devin web app. |
| Session in the web app | The whole thread is here too, so you can follow along in the browser. |
| Thread composer | When you're done, type archive to close out the session. |
| Archive reaction | Devin reacts with a box, and the session is archived. |
| Outro card | That's Devin in Slack. |
