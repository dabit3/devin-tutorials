# Devin in Slack — voice script

Narrated by Nader Dabit (ElevenLabs voice `T8iHhGIWPm2GVYpQD1Am`), generated as one take at the voice's default settings and cut into lines locally. Each line is a whole thought, kept in one piece so the tone stays even, and plays from the shot named on the left.

| Shot | Narration |
| --- | --- |
| Fresh #devin-runs channel | Once Devin is in a Slack channel, you can tag it from any message. Just type at Devin, and pick it from the list. |
| Typed !ask question | Start with bang-ask to get a quick answer about your code, without starting a full session. The answer comes back in a thread, with links to the code it read. |
| Typed !fast task | For real work, tag Devin with a task. Bang-fast runs it as a full Devin session in Fast mode, and a few minutes later, it replies in the thread with the total. |
| Thread composer | Reply in the thread to keep going. You don't need to tag it again. It picks up right where it left off. |
| Session link | Click the link to open the same session in the Devin web app. The whole thread is here too, so you can follow along in the browser. |
| Feature request | Now let's take it a step further and ask Devin to build a feature. Here, it adds a Clear done button to a kanban board, opens a pull request, and tests the change in the browser. |
| Test recording in the thread | When the tests pass, Devin sends the recording of its browser test right back to the thread. Open it, and you can watch it click Clear done and empty the Done column, before you even open the pull request. |
| Thread composer | When you're done, type archive, and Devin reacts with a box and archives the session. |
| Outro card | That's Devin in Slack. |
