# Devin tutorials

Short 4K (3840×2160, 60 fps) video tutorials for Devin, recorded from real, signed-in use of the Devin web app, the Devin CLI, Devin Desktop and Slack.

## Tutorials

1. **Ask Devin** (1:09): Ask questions about a codebase and get answers with code citations; click a citation to jump straight to the referenced lines. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/01-ask-devin/01-ask-devin.mp4)
2. **Your First Session** (1:51): Pick a repo, model and OS, describe a task, and watch Devin build a Kanban feature, open a PR, test it in its own browser and merge. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/02-first-session/02-first-session.mp4)
3. **Introducing Devin** (2:11): A tour of the Devin web app: sessions, Devin's own computer, Wiki, Automations and more, ending with a tested and merged feature. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/03-introducing-devin/03-introducing-devin.mp4)
4. **Secrets & Site Cookies** (1:22): Give Devin credentials without pasting them in chat: add organization or personal secrets (raw values, cookies, one-time passwords) and site cookies that keep it signed in to web apps. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/04-secrets-cookies/04-secrets-cookies.mp4)

6. **DeepWiki** (1:21): Read auto-generated wikis for your repositories, with architecture diagrams and cited source lines, and ask Devin questions that are answered from the wiki and your code. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/06-deepwiki/06-deepwiki.mp4)
7. **Automating Tutorials with Devin** (1:39): Tell Devin what to automate and when, approve the automation it drafts, or build one yourself with the form: triggers, a schedule and instructions for each run.
