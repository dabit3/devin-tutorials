# Devin tutorials

Short 4K (3840×2160, 60 fps) video tutorials for Devin, recorded from real, signed-in use of the Devin web app, the Devin CLI, Devin Desktop and Slack.

## Tutorials

1. **Ask Devin** (1:06): Ask questions about a codebase and get answers with code citations; click a citation to jump straight to the referenced lines. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/01-ask-devin/01-ask-devin.mp4)
2. **Your First Session** (1:57): Pick a repo, model and OS, describe a task, and watch Devin build a Kanban feature, open a PR, test it in its own browser and merge. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/02-first-session/02-first-session.mp4)
3. **Introducing Devin** (2:32): A tour of the Devin web app: sessions, Devin's own computer, Wiki, Automations and more, ending with a tested and merged feature. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/03-introducing-devin/03-introducing-devin.mp4)
4. **Secrets & Site Cookies** (1:19): Give Devin credentials without pasting them in chat: add organization or personal secrets (raw values, cookies, one-time passwords) and site cookies that keep it signed in to web apps. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/04-secrets-cookies/04-secrets-cookies.mp4)
5. **MCP Servers & Marketplace** (1:06): Connect Devin to your tools and data: add a custom MCP server (STDIO, SSE or streamable HTTP) or install one from the marketplace, so its tools are available in every session. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/05-mcp-marketplace/05-mcp-marketplace.mp4)
6. **DeepWiki** (1:15): Read auto-generated wikis for your repositories, with architecture diagrams and cited source lines, and ask Devin questions that are answered from the wiki and your code. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/06-deepwiki/06-deepwiki.mp4)
7. **Automating Tutorials with Devin** (1:32): Tell Devin what to automate and when, approve the automation it drafts, or build one yourself with the form: triggers, a schedule and instructions for each run. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/07-automations/07-automations.mp4)
8. **Testing Apps with Devin** (1:39): Ask Devin to test an app end to end; it drives the UI on its own computer and returns a recording with each check. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/08-computer-use-testing/08-computer-use-testing.mp4)
9. **Devin Review** (1:50): Open a pull request in Devin Review, run Devin's analysis to find bugs, ask about a finding, commit Devin's fix to the PR branch, and turn on automatic reviews. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/09-devin-review/09-devin-review.mp4)
10. **Devin CLI** (1:44): Run Devin in your terminal: permission modes (Accept Edits, Smart, Bypass), model selection, @ file context, /handoff to the cloud, /cloud sessions and devin ssh. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/10-devin-cli/10-devin-cli.mp4)
11. **Devin Desktop** (2:12): Devin's desktop app: the agent and model pickers, ACP agents, Quick Review, Codemaps, DeepWiki and a live localhost preview of the change. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/11-devin-desktop/11-devin-desktop.mp4)
12. **Devin in Slack** (1:13): Tag @Devin in Slack: `!ask` for a quick codebase answer, start a full session with a task, keep going in the thread, follow the same session in the web app and `archive` it when done. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/12-devin-slack/12-devin-slack.mp4)
14. **Devin Code Scans** (1:19): Type `/scan` with a focused request, confirm the setup card, watch findings arrive ranked by severity, then click Fix with Devin and follow one finding to its PR and focus-outline diff. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/14-devin-code-scans/14-devin-code-scans.mp4)
15. **Devin Playbooks** (1:20): Write a procedure once as a playbook with a `!before-after` macro, attach it to a new session with one macro, and get a PR with before and after screenshots. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/15-devin-playbooks/15-devin-playbooks.mp4)
16. **Devin Automations: events** (2:21): The ways automations can run (Slack, GitHub, schedules), the MCPs their sessions can use (Datadog, Sentry, Notion), and creating one in natural language. Then an automation with a GitHub Check run trigger (Conclusion = Failure) fires when CI fails on a pull request, starts a Devin session on its own, and Devin pushes the fix to the same branch until the check is green. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/16-automation-triggers/16-automation-triggers.mp4)
17. **Devin Security Swarm** (3:16): Let Devin generate a scan profile and walk through its sections, scan a repo with it in Interactive mode, review and approve the threat model, open a critical finding with its attack path, code and a Confirmed sandbox exploit, then assign it to Devin and end on the fix PR attached to the finding. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/17-security-swarm/17-security-swarm.mp4)
18. **iPhone and iPad apps on Mac VMs** (1:42): Pick macOS from the platform menu, ask for a universal SwiftUI app, and watch Devin build it with Xcode, run it in the iPhone and iPad Simulators from the Computer tab, test the iPad sidebar and Favorite button with Computer Use, record both runs and open a PR. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/18-ios-ipad-mac-vms/18-ios-ipad-mac-vms.mp4)
19. **Managed Devins** (2:04): Why one coordinator Devin with a team of managed Devins beats one long session, and where it fits (migrations, tests per module, one playbook across services, parallel research). Ask Devin to find the 4 least-tested components in orbit-demo and start a managed Devin for each, show them nested under the coordinator in the sidebar dropdown, steer one child through the coordinator, message the CardModal Devin directly and watch its Computer tab as it UI-tests the card modal in Chrome (Escape cancels, Save stores), then end on 4 PRs, the compiled summary and Settings → Preferences → Auto-approve child sessions, and close on a diagram of how managed Devins can start their own managed Devins, several levels deep. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/19-managed-devins/19-managed-devins.mp4)
20. **How Devin fits into your SDLC** (3:06): Short diagrams of where engineering time goes, the lifecycle phases and how Devin's PRs pass your branch protections and human review, then one real change to Orbit through the lifecycle: plan it with Ask Devin and its file citations, hand the plan to a Devin session that runs lint, build and a browser check and opens a PR using the repo's template, get a Devin Review first pass, fix a finding with a `/devin` comment in Devin Review, get a browser test recording, merge, then the security dashboard and connected repos. [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/20-sdlc-integration/20-sdlc-integration.mp4)

23. **Managed Devins: how it works** (overview, 1:16): A short diagram-led overview instead of a step-by-step run. One coordinator Devin splits a big task across managed Devins, each in its own isolated VM, monitors them, and compiles one summary; real shots from tutorial 19 show the four managed Devins, the sidebar tree, the PR summary and a message relayed through the coordinator, then Settings → Preferences → Auto-approve child sessions, the nesting tree, and four use cases (migrations, test coverage, one playbook across services, parallel research). [Download MP4](https://github.com/dabit3/devin-tutorials/raw/main/tutorials/23-managed-devins-overview/23-managed-devins-overview.mp4)

## Making a new tutorial

Every video's capture script, screenshots and edit spec live in [`tutorials/`](tutorials/), which also explains how to rebuild them. To create a tutorial for another Devin feature, use the reusable prompt in [`tutorials/TUTORIAL_PROMPT.md`](tutorials/TUTORIAL_PROMPT.md).
